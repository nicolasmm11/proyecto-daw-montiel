## 2. Nombre del proyecto

CardLab_TCG --> Una plataforma donde almacenar las cartas físicas de los usuarios y construir mazos.

## 3. Qué quiero hacer

Una plataforma donde se pueda almacenar una registro de las cartas física que un coleccionista o un jugar de cartas tenga, registrandolas en sesión desde un buscador y/o escaneándolas con el móvil. La web tendrá también un constructor de mazos vinculado a una base de datos de cartas como limitless y vinculada también al almacen personal mencionado anteriormente. La idea es que al construir el mazo, se remarquen las cartas que no tiene el usuario en propiedad  y que se pueda derivar a este a un marketplace como cardmarket para su posterior obtención.

## 4. Qué problema o necesidad resuelve

Resuelve la necesidad de un coleccionista o jugador de acceder al su almacen de cartas físico y bucear entre todas sus cartas en busca de las necesarias para contruir un mazo o realizar un seguimiento de su colección. 
Yo mismo, como coleccionista y jugador, tengo cientos de cartas organizadas en cajas por colecciones ordenadas. Cada vez que quiero construir un mazo o revisar las que tengo, tengo que acceder a la caja, sacar las cartas y arriesgarme a desordenarlas y/o estropearlas cada vez que las manipulo aún yendo con el cuidado que merecen. 
Teniendo un seguimiento digital de mi colección, así como un constructor de mazos enlazado con este, solo tendría que acceder a la caja una vez, cargarlas en sesión y, a partir de ahí, solo tendría que ver la aplicación web cada vez que quisiese revisarlas.
Del mismo modo, la derivación a un marketplace integrado ahorra mucho tiempo y hace automática la compra de cartas que sean necesarias sin hacer la busqueda manualmente.

## 5. Para quién

La aplicación web la utilizarían usuarios convencionales (jugadores, coloccionistas), principalmente, para uso personal.
